Discord Finance Task Bot

概要 / About

Discord Finance Task Bot は、Discord で受け取ったレシート画像を記録するための家計簿 Bot です。OAuth 認証は、画像を開発者本人の Google ドライブの指定フォルダに保存するためだけに使います。

Discord Finance Task Bot is a household budgeting bot that records receipt images received on Discord. It uses OAuth only to save those images to a designated folder in the developer's own Google Drive.

利用者 / Users

このアプリは個人用であり、開発者本人だけが使います。一般には公開していません。

This is a personal app used only by its developer. It is not offered to the public.
