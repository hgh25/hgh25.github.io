プライバシーポリシー / Privacy Policy

Discord Finance Task Bot（以下「本アプリ」）は、開発者本人だけが使う個人用アプリです。本ポリシーは、本アプリが扱う Google ユーザーデータについて定めます。

Discord Finance Task Bot (the "App") is a personal app used only by its developer. This policy describes how the App handles Google user data.

1. 取得するデータとスコープ / Data accessed and scopes

本アプリは Google Drive API を次のスコープで使います。

The App uses the Google Drive API with the following scope.

  • https://www.googleapis.com/auth/drive

このスコープで扱うのは、開発者本人の Google ドライブにある指定フォルダの情報（存在の確認）と、本アプリがそのフォルダに作成するファイル（レシート画像）です。それ以外のファイルの内容は読み取りません。

Under this scope, the App accesses only the metadata of one designated folder in the developer's Google Drive (to confirm it exists) and the files the App creates in that folder (receipt images). It does not read the contents of any other files.

2. データの用途 / How the data is used

取得したデータは、レシート画像を指定フォルダに保存し、その保存先リンクを家計簿の記録に残すためだけに使います。広告、分析、AI モデルの学習には使いません。

The data is used only to save receipt images to the designated folder and to keep a link to each saved image in the budget records. It is not used for advertising, analytics, or training AI models.

3. 第三者への提供 / Sharing with third parties

Google ユーザーデータを第三者に提供・販売・譲渡することはありません。

Google user data is never shared with, sold to, or transferred to any third party.

4. 保存場所と保存期間 / Storage and retention

保存したレシート画像は、開発者本人の Google ドライブにだけ置かれます。OAuth のトークンは、本アプリの実行環境に環境変数として保存し、アクセスを取り消すまで保持します。

Saved receipt images are stored only in the developer's own Google Drive. The OAuth token is stored as an environment variable in the App's runtime environment and is kept until access is revoked.

5. 削除方法 / How to delete data and revoke access

Google アカウントの「サードパーティ製のアプリとサービス」（https://myaccount.google.com/connections）から、本アプリのアクセスをいつでも取り消せます。取り消すとトークンは無効になります。保存済みの画像は Google ドライブから直接削除できます。

Access can be revoked at any time from "Third-party apps & services" in the Google Account (https://myaccount.google.com/connections). Revoking access invalidates the token. Saved images can be deleted directly from Google Drive.

6. Google API Services User Data Policy

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、Limited Use の要件を含む Google API Services User Data Policy に従います。

The App's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
